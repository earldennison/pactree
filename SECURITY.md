# Security Policy

## Supported versions

Only the latest 0.1.x release is supported with security fixes.

## Reporting

Report vulnerabilities privately through the repository's GitHub Security
Advisory "Report a vulnerability" flow. Do not open a public issue or include
credentials, captured context, or private Pact files in a report.

Include the affected version, a minimal reproduction, impact, and whether the
issue involves file parsing, path handling, credential exposure, or denial of
service. Maintainers will acknowledge a complete report within five business
days.
