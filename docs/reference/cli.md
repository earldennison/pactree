# CLI Reference

The authoritative command inventory is generated by `pactree --help` and
checked against `api/cli-help-v0.1.0.txt`. Use `pactree --version` to print the
release version.

Release-critical file commands:

```text
pactree file-validate <path>
pactree check <path>
pactree doctor <path>
pactree file-rewind-to <path> [branch] <revision>
pactree file-repair <source> <output> [--truncate-tail]
pactree heal <source> --out <output> [--truncate-tail]
```

Validation prints a JSON report and exits nonzero when `ok` is false. Repair
never overwrites its source and reports whether the repaired output validates.
Rewind accepts either `<path> <revision>` or `<path> <branch> <revision>`;
invalid numeric values are errors rather than silently ignored arguments.

Normal `pactree` readers reject pre-v0.1 Pact files with the typed error
described in the [file-format contract](file-format.md). Use the separate
`pact-v01-convert <source> <output>` utility for explicit conversion; it never
overwrites either input or output.

The complete generated help includes tree/store operations, branch and fork
operations, content and transaction tools, file inspection, query, search,
slice/import, views, and extension management. Commands removed from the
parser are not documented as aliases.
